## 视频说明

视频由实际应用画面、实际浏览器操作截图和说明卡剪辑，配离线合成中文旁白；不是一镜到底的连续录屏。

- 原生片段为 Ubuntu / IrisView 官方模拟器实际运行截图。
- 浏览器片段为共享业务逻辑的**资料摘录模式**，没有把固定资料标成在线AI结果。
- 视频中的语音卡介绍已实现流程，不是成功识别实录；真实人声准确率仍需继续优化。
- 不包含摄像头自动识别、视线追踪、定位导航或真眼镜已验收的主张。

采用英国国家美术馆历史展览「梵高：诗人与恋人」的三件作品作为资料样例，该展览已经结束。

## 实现与交付边界

原生应用使用 IrisView 公开 SDK 接口，本地后端可接 DeepSeek 与硅基流动音频模型；密钥由运行者在本机配置。已在 Ubuntu 实际启动 Client、模拟器和应用，并完成62项自动测试。语音已加入转写原文确认和低音量拒绝；补齐虚拟声卡后仍需真人复测。

GitHub Pages 版本只提供资料检索、文字对话、布局与歧义处理，不运行 Node 后端，不开放真实模型或云端语音调用，也不要求访客输入密钥。

原始开发者套件、`.env`、虚拟机配置、私人日志和迁移包均不随这份公开材料分发。
