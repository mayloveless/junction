# GitHub 在线体验

## 公开仓库与体验网页

公开仓库后，访客能查看代码、说明、图片和视频。要让 HTML 以可操作网页运行，还需要启用 GitHub Pages；仅公开仓库不会自动产生体验网页。

本项目已经提供 `web/` 静态页面和 `.github/workflows/pages.yml` 发布流程，不需要另外的平台、服务器账号或密钥。

## 启用步骤

1. 将本次材料与代码提交并推送至 `mayloveless/junction` 的 `main` 分支。
2. 在 GitHub 仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。
3. 打开 **Actions → Publish static experience → Run workflow**。以后修改 `web/` 并推送到 main，也会触发更新。
4. 工作流成功后，访问实际显示的部署链接。默认预期为：<https://mayloveless.github.io/junction/>。

上述链接是按仓库名推算的预期地址。仓库材料提交与网页部署是两个步骤；只有Pages工作流实际成功后才能标为已经上线。仓库可见性与Pages设置由仓库拥有者控制。

## 可体验范围

- 三件作品的选择与馆方资料摘要。
- 文字追问、精简、调整关注点。
- 字号、标准/精简/重点卡、位置与分页。
- 不明确作品的候选确认、资料不足提示。
- 在同一页面播放演示视频。

在线版明确为资料摘录模式。真实 DeepSeek 和语音 API 需要后端运行；GitHub Pages 是静态托管服务，不能直接运行本项目的 Node 后端，也不应把 API Key 写进网页。

本地预览可在项目根目录运行：

```bash
python3 -m http.server 4319 --bind 127.0.0.1 --directory web
```

访问 <http://127.0.0.1:4319/>，无需 `.env`。

官方依据：[GitHub Pages 介绍](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)、[自定义 Pages 工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。
