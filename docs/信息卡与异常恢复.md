# 信息卡与异常恢复验收

日期：2026-11-07。

## 最终行为

- 长讲解按字号和布局分页，正文、来源、提示与底部按钮保留边界。数字与馆藏编号在可容纳时整段换行，避免把“15”或“NG3863”从中间拆开；常见中文标点避免独立起行，书名号避免悬挂在行末。
- 浏览器显示当前页/总页数，在首末页禁用相应按钮；原生导航同样禁用边界按钮，文字/语音翻页也会限界，不再积累不可见页码。
- “精简卡”只改布局，“再精简”才改内容；重复指定已生效布局不调用AI、不追加历史。
- 讲解失败可重试同一问题；已有有效讲解可返回，并恢复该讲解对应的关注点、篇幅与原问题，后续追问不会沿用失败问题。
- 语音错误提供重新录音与文字入口；不会把旧的失败讲解当成当前录音重试。
- 原生呈现失败只重新呈现已有讲解，申请新的公开presentation fence；不重新调用AI、不重复对话历史。
- 处理中显示实际阶段和排队数量。没有旧答案时显示读取资料/等待麦克风等状态，不再提示用户选择已经选过的作品。
- 异常与待确认画面不引用上一份答案的资料，避免把旧来源误当成错误提示或候选项的依据。
