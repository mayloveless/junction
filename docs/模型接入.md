# 模型接入与选择

核对日期：2026-11-07。选择以用户提供的可用模型清单为准。

讲解继续使用已接通的 DeepSeek 官方接口，当前本机模型为 `deepseek-flash`，两条在线样本通过。清单中的 `deepseek-ai/DeepSeek-V3.2` 是平台模型 ID，不能直接当作 DeepSeek 官方模型 ID 使用；若以后要将讲解也迁到硅基流动，需要另行适配和验证。

语音从可用清单中选择 `Qwen/Qwen3-Omni-30B-A3B-Instruct`。硅基流动官方多模态文档明确 Qwen3-Omni 支持音频输入，使用 `/chat/completions` 的 `audio_url`，可以传完整 WAV 的 data URL。适配代码已实现，独立密钥已加载。首次请求返回402；用户充值后，两段合成语音在线转写、语音生成讲解、语音调布局及文字追问均通过。4.10秒音频转写1849ms，2.39秒音频转写1753ms，仅为两次合成样本。

流程：SDK 采音 → 后端用 Omni 逐字转写 → 同一个会话 controller → 检索当前作品资料 → DeepSeek 生成有依据的讲解 → ARUI。Omni 不接收展品资料与对话历史，提示其只转写、不总结、不回答语音里的问题。现有流程为结束录音后上传，没有声称已实现实时流式识别。

| 可用候选 | 首版判断 |
| --- | --- |
| Qwen3-Omni Instruct | 当前选择，用于音频转文字；两段合成音频已通过；真实人声、专名及展厅噪声仍待实测。 |
| Qwen3-Omni Thinking | 不优先，当前任务只需转写。 |
| Qwen3-Omni Captioner | 侧重音频描述，不优先用于逐字转写。 |
| Qwen3-VL 系列 | 硅基流动文档明确无音频输入，不作为转写模型。 |
| CosyVoice2 / MOSS-TTSD | 语音合成，用于以后需要读出讲解时另行评估。 |

此前推荐的 Qwen3-ASR-1.7B、SenseVoiceSmall 不在用户可用清单，本轮不采用，也不沿用其价格估算到 Omni。Omni 按平台对应模型的 token 价格计费；官方说明音频输入每秒约13 token，另计输出，实际以账单为准。

配置已预留 `ASR_PROVIDER=siliconflow`、`ASR_API=chat-completions`、`SILICONFLOW_API_KEY`、`ASR_BASE_URL=https://api.siliconflow.cn/v1/`、`ASR_MODEL=Qwen/Qwen3-Omni-30B-A3B-Instruct`。硅基流动独立密钥已填写并重启服务；DeepSeek 密钥不会发给硅基流动。可用 `node tools/check-voice-live.cjs` 重试现有两段合成音频与文字追问验证，结果写入 artifacts/voice-live-check.json。

先录制同一批10–20条短音频，包含安静和有背景人声两组。重点检查“梵高、高更、罗讷河、向日葵、有柏树的麦田”等专名，以及“再短一点、只讲构图、字大一点”等指令；记录专名错误、指令误识别、空结果和结束录音至转写完成的耗时。还要测试静音、噪声与语音里的诱导指令。生成式转写可能改写或臆造，不能仅凭请求成功就视为识别准确；允许文字纠正。
