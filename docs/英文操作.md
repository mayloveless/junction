# 英文控制指令

Client文字输入框输入后，点击“提交文字”。讲解输出继续使用中文。以下完整指令在应用本地识别；字号、卡片和位置操作不调用模型。

| 输入 | 操作 |
| --- | --- |
| font size larger | 大字号 |
| font size smaller | 普通字号 |
| compact card | 精简卡 |
| focus card | 重点卡 |
| standard layout | 标准卡 |
| bottom / top | 底部 / 顶部 |
| make it shorter | 沿用当前作品和问题，重新生成精简讲解 |
| more details | 沿用当前问题，展开讲解 |
| next page / previous page | 翻页 |
| cancel / retry | 取消 / 重试 |
| start recording / stop recording | 原生Client开始 / 结束录音 |
| confirm | 确认识别原文后再生成讲解 |
| background / composition / materials | 当前作品的创作背景 / 构图 / 材料 |

组合示例：`font size larger, compact card, bottom`。可加please；控制句以逗号或and连接。包含其他问题内容时仍按问题处理，避免把作品中的字体问题误判为显示命令。

选择作品可在Client使用方向键移动焦点，再按“确认”。Simulator显示画面。原生语音识别和录音仍需在Client中实际验收。
