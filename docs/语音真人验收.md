# 语音真人验收清单

目标：确认自己的声音能在浏览器里完成提问、追问和改布局。合成语音通过不等于真人或眼镜麦克风通过。

2026-11-07 用户反馈“语音测试能识别”，基础真人识别记为用户报告成功。未提供逐条结果、浏览器、麦克风与噪声条件，以下完整清单仍保留待测。

打开 `http://127.0.0.1:4317`，推荐 Chrome。点击「开始录音」，允许麦克风；正常说完后点击「结束并发送」。如果音量条始终不动，先检查浏览器/系统麦克风权限与输入设备。

先在安静环境按顺序测试；再用正常交谈音量，在有背景人声的环境重复。不要为了测试刻意大声喊，也不要把合成白噪声测试当作展厅实录。

逐条记录：浏览器、麦克风、安静/背景人声、实际转写、是否选对作品/执行对指令，以及主观等待是否可接受。专名错误与指令错误分别记录；不要只看总字错率。

字错后可在文字框直接修改再发。若权限一直等待，可取消并在 Chrome 地址栏的站点设置里允许麦克风，再重录。每条最多60秒；切换作品、开始打字或隐藏页面会中止当前录音/识别并放弃旧结果。

自动合成测试：`python3 tools/prepare-voice-benchmark.py` 生成8条语句的安静/15dB白噪声两组，`node tools/check-voice-benchmark.cjs` 调用真实ASR并在资料模式的controller中检查意图。结果位于 `artifacts/voice-benchmark/results.json`；不将这些结果填入本表的“真人结果”。
